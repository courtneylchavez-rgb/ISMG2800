Understanding JavaScript If/Else Statements

Learn how JavaScript makes decisions using conditions.

Introduction How It Works Examples Try It Yourself

What Is an If/Else Statement?

An if/else statement is a feature in JavaScript that allows a program to make decisions. It checks whether something is true or false and then decides which code to run.

For example, a website could use an if/else statement to check someone's age. If the person is 18 or older, they can continue. Otherwise, the website can display a message saying they are too young.

Think of it this way: If it is raining, bring an umbrella. Else, leave the umbrella at home. The program chooses what to do based on the condition.

How Does If/Else Work?

An if/else statement has three main parts:

  1. if: Checks whether a condition is true.
  2. else if: Checks another condition if the first one is false.
  3. else: Runs when none of the previous conditions are true.

Basic Syntax


if (condition) {
    // Code runs if the condition is true
} else {
    // Code runs if the condition is false
}

The condition goes inside parentheses. The curly brackets contain the instructions JavaScript should follow. If the condition is true, JavaScript runs the first section. If it is false, JavaScript runs the else section instead.

JavaScript If/Else Examples

Example 1: Checking Age

This example checks whether someone is old enough to vote.


let age = 20;

if (age >= 18) {
    console.log("You are old enough to vote!");
} else {
    console.log("You are not old enough to vote.");
}

Since the age is 20, the condition age >= 18 is true. JavaScript displays the first message.

Example 2: Using Else If

An else if statement allows JavaScript to check multiple conditions. This is useful when there are more than two possible outcomes. 


let grade = 85;

if (grade >= 90) {
    console.log("You got an A!");
} else if (grade >= 80) {
    console.log("You got a B!");
} else if (grade >= 70) {
    console.log("You got a C!");
} else {
    console.log("You need to study more.");
}

In this example, the grade is 85. The first condition is false, but the second condition is true. JavaScript displays "You got a B!" and skips the remaining conditions.

Example 3: Checking the Weather


let temperature = 75;

if (temperature > 80) {
    console.log("It is hot outside!");
} else if (temperature >= 60) {
    console.log("The weather is nice!");
} else {
    console.log("It is cold outside!");
}

Because the temperature is 75, JavaScript displays "The weather is nice!"

Comparison Operators

Comparison operators are used inside if/else statements to compare two values. They help JavaScript determine whether a condition is true or false.

  • == Equal to (compares values).
  • === Strictly equal to (compares value and data type).
  • != Not equal to.
  • !== Strictly not equal to.
  • > Greater than.
  • < Less than.
  • >= Greater than or equal to.
  • <= Less than or equal to.
Example: if (10 > 5) is true because 10 is greater than 5. JavaScript will run the code inside the if statement.

Why Are If/Else Statements Important?

If/else statements are important because they allow websites and applications to respond differently depending on what a user does or enters. Without them, programs would have a harder time making decisions.

They can be used for:

  • Checking passwords and login information.
  • Determining if someone is old enough to access something.
  • Giving students letter grades based on scores.
  • Showing different messages based on user choices.
  • Checking whether information entered into a form is correct.
